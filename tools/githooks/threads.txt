# Thread ownership map -- read by tools/githooks/commit-msg.
#
# Several Claude sessions work on this repo at once (see CLAUDE.md "Concurrent sessions").
# Each [thread] lists the files that belong to it (fnmatch globs, repo-relative). A commit may
# touch ONE thread's files plus any number of shared files (anything not listed here: README,
# NOTES, MERGE, CLAUDE.md, reference/kb/*, ...). A commit that mixes two threads' files is
# refused -- that is exactly what a repo-wide `git add -A` in a shared checkout produces, and
# it happened twice on 2026-09-27 (10173b3, eb8f022).
#
# Add a new thread's files here BEFORE its first commit. First match wins.
#
# OCTABAM MODULE FOLDERS (one per shipped feature: manifest.py + its sources + README.md)
# are listed under the thread that actually EDITS the source in them -- DIRECT JUMP's cave
# source is still the directjump thread's file, wherever it lives. The four modules with no
# live thread (batch-bugfixes, reload-from-project, quantize-live-rec-toggle,
# erase-empty-trigless-locks) are deliberately NOT listed: their builders in tools/ are not
# listed either, so a commit touching a builder and its module folder together stays a
# "shared files only" commit instead of being refused for mixing two threads.
